- macOS 15.6.1
- Docker 29.5.2
- Git 2.51.0

- npm 11.19.1
- Ollama 0.40.16
- Qwen3:0.6b (7df6b6e09427)
- promptfoo 0.121.17

## Структура проєкту

- docs/ — тестові документи основної частини.
- docs_individual/ — документи індивідуального завдання.
- promptfooconfig.yaml — конфігурація основного тестування.
- promptfooconfig.individual.yaml — конфігурація індивідуального завдання.
- .nvmrc — фіксація основної версії Node.js.
- README.md — документація проєкту.

## Запуск середовища

```bash
docker run -d --name ollama \
  -v ollama:/root/.ollama \
  -p 127.0.0.1:11434:11434 \
  --memory=2g --cpus=2 \
  ollama/ollama:0.40.16
```

## Завантаження мовної моделі

```bash
docker exec -it ollama ollama pull qwen3:0.6b
```

## Запуск основного тестування

```bash
npx promptfoo@0.121.17 eval
npx promptfoo@0.121.17 eval --no-cache
```

## Запуск індивідуального завдання

```bash
npx promptfoo@0.121.17 eval -c promptfooconfig.individual.yaml
npx promptfoo@0.121.17 eval -c promptfooconfig.individual.yaml --no-cache
```

## Перегляд результатів

```bash
npx promptfoo@0.121.17 view
```
